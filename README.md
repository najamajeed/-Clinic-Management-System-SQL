# Clinic-Management-System-SQL
A Clinic Management System database project using MySQL. Includes patients, doctors, departments, appointments, and billing tables with primary keys, foreign keys, and an ER diagram.

Project Overview

This project is a Clinic Management System database created using MySQL. It helps manage patient details, doctor information, departments, appointments, and billing records.

Database Tables

The database consists of five tables:

* Patients: Stores patient details such as name, age, gender, and phone number.
* Doctors: Stores doctor information, specialization, and department ID.
* Departments: Stores department information.
* Appointments: Manages patient appointments with doctors, including appointment date and status.
* Bills: Stores billing details, total amount, and payment status.

Database Relationships

* One patient can have multiple appointments.
* One doctor can have multiple appointments.
* One department can have multiple doctors.
* Appointments are connected to billing records.

Tools Used

* MySQL
* MySQL Workbench

Project Files

* SQL Database File
* ER Diagram

Project Objective

To understand relational database design, table relationships, primary keys, foreign keys, and basic SQL concepts through a practical project.
